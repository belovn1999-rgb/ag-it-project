Правила для сессий волн: своя рабочая копия от ветки `design-9` (`git worktree add`), `vendor` и `node_modules` — копией
из `~/cloude/mantexlab-tools-design/platform` (`cp -Rc`), своя SQLite и порт; только вид (логика, тексты, `data-test`
не меняются); перед выкладкой — скриншоты «было / стало» и «Выкладывать?»; 9.0 уже в `main` (23.10) —
перед push своей волны `git fetch && git rebase origin/main` (коммит `a610fac` git пропустит сам).

Что выяснилось в 9.0: (1) детали Flux нельзя заворачивать в свои компоненты, если внутри дочерние `flux:radio` —
они не видят настройки группы (обёртку переключателя убрали, 44 px задаёт правило в `app.css`); (2) Flux делает
серой подпись всей группы, если внутри есть недоступный вариант — для таких вопросов своя подпись над группой;
(3) панель Flux (`flux:popover`) не закрывается от ответа Livewire — звезда в папке истории работает, выбор строки
закрывает панель.

Что выяснилось в 9.1–9.3: (1) `flux:tabs` работает только внутри `flux:tab.group` (без неё переключение не уходит на
сервер), панели не нужны — содержимое меняет сервер; (2) действия второго компонента на той же странице (BY) ставятся в
шапку через Livewire `@teleport` в место с `wire:ignore` — кнопки и папка остаются за своим компонентом; (3) строчный
`@php(...)` ломается, если ниже в файле есть блок `@php … @endphp` (Blade склеивает их) — писать блоком; (4) у
сегментов, где сервер может выбрать не то, что нажато (доставка BY, тарифы), — `wire:click` + `:checked` и `wire:key`
с выбранным значением вместо `wire:model`; (5) окно Flux, которое закрывает только своя функция с вопросом:
`:dismissible="false" :escapable="false" :closable="false"` и свой обработчик нажатия мимо; (6) открытая
`flux:accordion` не сворачивается после ответа Livewire.
