# Справочник моделей против объявлений платформы

Этап B61 п. 18 (`docs/PROJECT-MODELS.md`), замер 2026-10-25. Объявления — те, что платформа «Поиск дилеры» уже прочитала (выгрузка с сервера только технических полей: портал, марка и модель подборки, год, топливо, кВт, коробка, страна; без пользователей и клиентов), сопоставление — `platform/tools/portals/check-coverage.php` (функция платформы `ModelSpecs::select()`: поколение на год объявления, версия того же топлива с мощностью ± 2 кВт). Мерило владельца (23.10): объявления легковых с 2010 года, ≥ 98 % находят свою версию.

**Итог: 97.7 %** — 1954 из 1999 объявлений (всего прочитано 2860). Выборка пока узкая: в основном Audi, Toyota, BMW, Hyundai — то, что искали менеджеры; по остальным маркам цифры появятся с новыми подборками. Marktplaats, Blocket и ParuVendu не дают мощность в выдаче — их объявления в замер не входят.

Правила сопоставления, которые учитывают запись порталов: AutoScout24 называет плагин-гибрид «hybrid» (Audi Q5 55 TFSI e, BMW 330e); у полного гибрида портал часто даёт мощность только бензинового мотора (Toyota C-HR 1.8 Hybrid — 72 кВт при 90 кВт системы, Kona Hybrid — 77 / 104 кВт) — такие засчитаны отдельной строкой; объявление подборки, которую потом переделали на другую машину, сопоставляется по своим марке и модели.
