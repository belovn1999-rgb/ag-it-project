# 4. Проверка VIN

Цель: сделать внутреннюю проверку VIN через partslink24 и получать PDF-отчет без ручного входа, кликов и переименования файла.

## Поля проверки

1. Язык: `RU` / `PL` / `ENG`
2. Марка авто
3. VIN для проверки

| Mercedes-Benz | Сначала плитка `Mercedes-Benz`, потом VIN внутри марки | `WDD2120481A322032` | `PL` | Да |

## Правило распознавания данных из отчёта

Применяется ко всем маркам, в том числе к тем, что будут проверяться дальше. Отчёт читается через `pdftotext -layout`, поэтому таблица разносится по колонкам, и наивный поиск подстроки по всему документу даёт ложные срабатывания.

1. **Код опции засчитывается только как строка списка оборудования** — то есть с начала строки, в формате `КОД Описание`. Пример ошибки: у BMW код `S1CEA` («Рекуперационная система») встречается ещё и в таблице объёмов заливки как `Coolant NT S1CEA (2,82l)`, из-за чего обычный бензиновый 218i определялся как мягкий гибрид.
2. **Короткие токены не склеиваются через пробелы.** Между частями названия допускается только знак пунктуации: бейдж Stellantis пишется `H:DRIVE`, и одиночная `H` в одной колонке рядом со словом `DRIVE` в другой не должна давать MHEV. Пробелы выше по коду схлопываются в один, поэтому пробел как разделитель здесь запрещён.
3. **Описательные фразы** (`mild hybrid`, `мягкий гибрид`, `belt starter generator`, `PHEV`) ищутся по всему тексту без привязки — они однозначны.
4. **Каждый разбор подтверждается тестом** в `tools/partslink24/report-extraction.test.mjs`: и положительный случай (признак есть), и отрицательный (похожая строка, но признака нет).

## Тип двигателя в отчётах Stellantis

У Stellantis (Fiat, Peugeot, Citroen, Opel, Jeep, Alfa Romeo, DS, Lancia) силовой агрегат описан отдельными строками таблицы данных, и читать нужно именно их, а не описания оснащения:

| Поле | Что означает |
| --- | --- |
| `CMB` | тип топлива: `EL` — электрический, `BE` — бензин/электро |
| `ELT` | тип электрификации: `BEV`, `MHEV`, … |
| `EKW` | мощность электромотора, кВт |
| `ENG` | силовой агрегат, например `= BEV (370KM RANGE)` или `= 1.2 BZ MHEV 136 CV` |
| `TRM` | коробка передач; «непосредственный электрический привод» означает отсутствие ДВС-коробки |

**BEV — отдельная категория и решается первой.** Если строки говорят `ELT BEV`, `ENG … = BEV` или `CMB EL`, тип двигателя — «Электрический», и признаки MHEV/HEV/PHEV дальше не ищутся. У электромобиля зарядный порт и кабели установлены штатно, а каталог подписывает их `EV/PHEV` — без этого правила такая машина определяется как подключаемый гибрид.

Обратный случай тоже важен: у не-электрической машины те же строки оснащения перечислены со значением «Нет» — это отсутствующее оборудование, и доказательством оно быть не может.

## Критерий успешного PDF

PDF считается успешным, если:

- файл создан и не пустой;
- `Subject` в метаданных PDF равен VIN;
- `Keywords` содержит `partslink24`;
- `Keywords` содержит ожидаемую марку;
- текст PDF содержит VIN.

Дополнительные проверки:

- BMW: в тексте ожидаются `Идентификация автомобиля`, `Серийная комплектация` или `Спецоборудование`.
- Mercedes-Benz: в тексте ожидаются `identyfikacja pojazdu`, `Wyposazenie` или `SAA Numbers`.
- Volvo: в тексте ожидаются `identyfikacja pojazdu`, `Wyposazenie` или `Informacje techniczne`.
- Peugeot: дата производства не обязательна; в тексте ожидаются `Идентификация автомобиля`, `Модель` и `Оснащение`.
- Audi: в тексте ожидаются `identyfikacja pojazdu`, `Data produkcji` и `Wyposazenie`.

## Пароли и доступы

Нельзя хранить в GitHub:

- partslink24 ID компании;
- имя пользователя;
- пароль;
- cookies/session storage браузера;
- реальные скачанные клиентские PDF, если они не нужны как тестовые артефакты.

Правильное место для секретов:

- локальный `.env` на Mac или сервере;
- переменные окружения на сервере;
- GitHub Secrets, если позже будет CI/CD без запуска самой браузерной автоматизации.

Пример закрытого `.env`:

```text
PARTSLINK24_COMPANY_ID=...
PARTSLINK24_USERNAME=...
PARTSLINK24_PASSWORD=...
PARTSLINK24_DEFAULT_LANGUAGE=RU
```

Файл `.env` должен быть закрыт через `.gitignore`.

## Команды для локальной проверки

Перед запуском нужно задать секреты только в локальном окружении:

```bash
export PARTSLINK24_COMPANY_ID="..."
export PARTSLINK24_USERNAME="..."
export PARTSLINK24_PASSWORD="..."
```

Проверка BMW через partslink24:

```bash
node tools/partslink24/download-vin-pdf.mjs \
  --brand BMW \
  --vin WBA31AA0905V40977 \
  --language RU \
  --headed
```

Проверка готового PDF:

```bash
node tools/partslink24/validate-pdf.mjs \
  output/partslink24/BMW_WBA31AA0905V40977_RU.pdf \
  --brand BMW \
  --vin WBA31AA0905V40977
```
