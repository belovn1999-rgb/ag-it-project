## 2. Правила для чатов (CONFIRMED)

1. **На платформе нет названия AUTOGOOD**: ни в коде, ни в текстах, ни в коммитах, ни в именах файлов. Компания —
   «первый клиент». Продукт продаётся многим дилерам: числа первого клиента (страны, комиссия, тарифы) — настройки,
   не код.
2. Данные и логику берём из этого репозитория (справочники, правила фильтров, формулы) и переписываем на PHP; код как
   есть не копируем. Справочники собирает `platform/tools/portals/build-catalogs.mjs` из этого репозитория.
3. Защиту порталов не обходим; mobile.de с сервера не читается — только браузером менеджера (расширение).
4. Перед работой: `git pull` в `~/cloude/mantexlab-tools`; параллельно работают чаты шефа — свести правки, сохраняя
   обе стороны. В том же коммите: `docs/contracts/portals.md` и строка/статус в `docs/board.md` платформы, здесь —
   журнал в `PROJECT_BRAIN.md` §8.
5. Проверка до выкладки (на Mac нет системного PHP): `~/cloude/.tools/php-common/php vendor/bin/pest` (все тесты),
   `… vendor/bin/pint --test` (оформление), анализатор `… vendor/bin/phpstan analyse` — без новых замечаний.
   Ассеты для тестов: `~/cloude/.tools/node/bin/npm ci && npm run build` в `platform/`.
6. Выкладка — только с разрешения владельца в чате: push в `main` платформы, затем на сервере `git pull --ff-only`,
   кэши и перезапуск очередей (команды — `~/cloude/CLAUDE.md`), проверка `https://tools.mantexlab.com/up` = 200 и
   сайта `https://autogood.mantexlab.com/` = 200. Миграции базы — только по прямому «да» владельца.
