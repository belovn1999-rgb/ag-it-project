## 1. Зачем проект

Внутренние инструменты менеджера AUTOGOOD (импорт авто из Европы в Польшу): калькуляторы стоимости, договоры и документы (DOCX/PDF), проверка VIN, поиск и анализ рынка mobile.de / otomoto, обработка отчётов аукционов. Цель: быстрее и точнее готовить расчёты и документы для клиента.

## 3. Как тестировать

- Фронтенд локально: `python3 -m http.server 4173 --bind 127.0.0.1` → `http://127.0.0.1:4173/`.
- Портал сменил страницу (письмо «Portals health» или сломанный разбор): `node scripts/portals/health.mjs <портал>` → правка разборщика → `node scripts/portals/capture-fixtures.mjs <портал>` (новый обезличенный образец) → тесты.
- Проверки CI до push (`pnpm run verify` падает письмом владельцу): глобального `node` на Mac нет, есть `~/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node` — им `scripts/check-js.mjs`, `scripts/test-mobile-search-model-version.mjs`, `scripts/audit-mobile-search.mjs --offline`.
- Импортер mobile.de: `127.0.0.1:8788`, туннель через LaunchAgent. Рецепт перезапуска в [PROJECT-MOBILE.md](PROJECT-MOBILE.md) (раздел про туннель).
- Проверка VIN: бэкенд `4174`, работает из копии-зеркала вне репозитория. Правка `tools/partslink24/*` или `server/*` начинает действовать только после копирования в зеркало.
- Quick-туннели запускать **без** `--protocol http2`. URL меняется при каждом перезапуске, проверяй заново.
- Тестовая ссылка: `<страница>.html?api=https://<tunnel>.trycloudflare.com`.
- Оффер с аукциона (статичные страницы, бэкенд не нужен): сервер только на папку кода (`python3 -m http.server 4181 --bind 127.0.0.1 --directory <checkout>`, не на `~/cloude` — там образцы отчётов с VIN) → `cloudflared tunnel --url http://127.0.0.1:4181` → `<tunnel>/oferty.html?tryb=aukcja&raport=<ссылка отчёта>`. Черновики офферов живут в браузере на адресе туннеля.

## 4. Как выкатывать

- `main` → GitHub Pages: https://belovn1999-rgb.github.io/ag-it-project/
- `./scripts/publish.sh "сообщение"` (коммит, push, проверка). Подробно в [RELEASE_RUNBOOK.md](RELEASE_RUNBOOK.md).
- Поднимать `?v=` у изменённых ассетов. `src/main.jsx` вручную зеркалится в `src/main.compiled.js` (сборщика нет).
- Конвертер DOCX→PDF деплоится **отдельно** на Render, проверка через `/api/health` → `revision`.
- Готово = изменение видно на живом URL, а не только запушено.

## 5. Ключевые правила (для всех областей)

- **Данные пользователя в браузере не теряются никогда** (избранное, история, сохранённые расчёты и договоры): правила в [PROJECT-MOBILE.md](PROJECT-MOBILE.md) §4.6.1, действуют для всех страниц.
- Правка «во всех калькуляторах/договорах» = все однотипные страницы, перечисли их перед работой.
- В репозиторий не попадают пароли, токены и ключи (репозиторий публичный).
- **Акциз: любой гибрид, мягкий (MHEV, 12 В и 48 В) тоже, — льготная ставка во всей Польше** (1,55 % до 2000 см³, 9,3 % больше; владелец 2026-10-11) — во всех калькуляторах, анализе, Monitoring, оффере. Порталы пишут MHEV как обычный бензин/дизель: фильтры и подборки считают его бензином/дизелем, MHEV определяется по таблице моделей ([MODEL-MILD-HYBRIDS.md](MODEL-MILD-HYBRIDS.md), PROJECT-MOBILE.md §4.8 п. 3).
- **Акциз коммерческих: фургон N1 (ciężarowy / dostawczy) — 0 %** (в Польше акциз только с легковых; владелец 2026-10-11); пассажирские версии фургонов (M1: Tourneo, Kombi, Caravelle, кемперы) — как легковые. В программах — класс двигателя 5 «Dostawczy N1».
- Правила конкретной области записываются в её файл из карты, а не сюда.
- **Номера задач** (B…): следующий после самого большого на свежем `main`; занятый номер получает суффикс «.2» («B74.2») — PROJECT-MOBILE.md §2 п. 14.
- **§0 «Текущая ситуация и план»** (PROJECT-MOBILE.md) обновляет чат, который меняет этап; куратор сверяет по журналу.
