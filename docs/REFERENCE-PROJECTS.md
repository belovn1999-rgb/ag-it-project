## 4. Не брать

- Дубли по «название + цена» (deal-finder) — наши (цена + пробег + год) точнее.
- Модель машинного обучения для цены (autoscout-analyser) — нужны сотни тысяч объявлений
  и переобучение; медиана понятнее клиенту.
- Обход защиты: Camoufox (Ricardo), SeleniumBase (autoscout24-trends), подмена отпечатка
  браузера (avby-bot), вход в Facebook — у нас открытые API и свой Worker.
- Facebook Marketplace — риск блокировки аккаунта.
