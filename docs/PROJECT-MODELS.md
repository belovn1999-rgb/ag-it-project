### 4.8 Справочник моделей и зависимые фильтры (B61, с 03.10.2026)

**Цель (владелец, 03.10):** фильтры стр. 1 сужают выбор по реальной базе
автомобилей: Marka → Model → поколение → версии двигателя (объём, мощность,
топливо) → комплектация → основные данные. После выбора годов в полях
«Pojemność» и «Moc» видны двигатели, которые у этой модели в эти годы
существуют, а не общий список. Зачем: менеджеру не нужно проверять версии на
сторонних сайтах; запрос клиента собирается точнее; выборка для анализа — по
конкретным параметрам. Источник базы — **ultimatespecs.com**. Сейчас — 65
популярных моделей 10 марок, позже — остальные.

**Кузова, двери, места (B70, 10-04, владелец):** `tools/build-model-specs.py`
пишет каждой модели `bodies` = [поколение, типы, двери от–до, места от–до,
сдвижная дверь] из названий кузовов ultimatespecs (`body_of`: слова Avant /
Variant / Touring / SW / Combi → Kombi, Sedan / Limousine → Sedan, Cabrio →
Cabrio, Coupe → Coupe, Gran Coupe / CLA → Coupe + Sedan, «3 Doors» / «5 Doors»
→ двери; модели-SUV и VAN списком; без слова — тип модели по умолчанию; 7 мест —
Q7, X5, XC90, Kodiaq, 5008, S-Max, Grand C-Max, Grand Scenic, Touran, Allspace,
GLE; T6 и Trafic — 2–9 мест и сдвижная дверь). На стр. 1 по выбранным годам
(без годов — все поколения) приглушаются «Nadwozie», «Liczba drzwi»,
«Liczba miejsc», «Drzwi przesuwne» (`AUTOGOOD_COMBO_UNAVAILABLE` для списков) —
как «Typ»: серое, но кликабельно. Строка «Pokolenia: …» под «Rok» убрана
(поколения видны в самом списке).

**Правила работы с ultimatespecs.com:**
- `robots.txt`: **Crawl-delay: 30** — не чаще одной страницы в 30 с. Полная
  пересборка двигателей ≈ 4,6 ч, поколений ≈ 35 мин. Страницы кэшируются,
  повторный запуск догружает только недостающее. Запуск — на Mac владельца
  (сайт отвечает обычному curl).
- Структура: марка `/car-specs/<Brand>-models` → модель
  `/car-specs/<Brand>-models/<Brand>-<Model>` (поколения `<h2>Имя (год - год|Present)</h2>`,
  кузова со ссылкой и «N Versions») → кузов `/car-specs/<Brand>/M<id>/<имя>`
  (таблицы `versions_div` по топливу: Petrol / Diesel / Plugin Hybrid…;
  строка = название, год, «hp / kW», «cm³»).
- Данные берутся как есть; найденные ошибки источника перечисляются в начале
  `docs/MODEL-*.md` (снятые модели с «н. в.»: Mondeo 5, S-Max 2, Auris 2,
  Camry XV50, T6.1; Kuga — путаница поколений; нет RAV4 2025, Camry XV80).
- Годы ultimatespecs — модельные; рестайлинг — отдельное поколение; годы
  соседних поколений могут пересекаться.
