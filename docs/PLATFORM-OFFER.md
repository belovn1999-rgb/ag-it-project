## 2. Правила для чатов оффера (CONFIRMED 17.10)

1. Все правила `PLATFORM-SEARCH.md` §2 действуют и здесь: нет слова AUTOGOOD на платформе (код, тексты, коммиты,
   файлы; там «первый клиент», «фирма»); числа первого клиента — настройки компании; логику и данные переписываем на
   PHP, код как есть не копируем; защиту порталов не обходим, mobile.de — только браузером менеджера.
2. **Своя копия кода:** `git -C ~/cloude/mantexlab-tools worktree add <папка> -b <ветка> origin/main`; своя
   `platform/.env` с SQLite и своим портом (занято: 8123 — основная копия, 8124 — поиск, 8125 — второй разбор поиска;
   оффер — 8126 «расчёт и лист», 8127 «mobile.de»). Коммит только явными путями, перед ним `git diff --cached --stat`.
3. Проверки до показа: `~/cloude/.tools/php-common/php vendor/bin/pest` (все тесты), `… vendor/bin/pint --test`,
   `… vendor/bin/phpstan analyse` — без новых замечаний; тест на каждый пункт волны.
4. **Порядок волны:** исполнитель делает правку, тесты, локальные скриншоты (десктоп и 375 px) и коммит в своей ветке
   (без push) → отчёт куратору с номерами пунктов → куратор проверяет и показывает владельцу «Выкладывать?» → после
   «выкладывай» владельца **куратор** сводит ветку в `main`, push, выкладка на сервер, проверка вживую, мозг и доска.
   Исполнители сами на сервер не выкладывают. Миграции базы — только по прямому «да, миграция» владельца для этой волны.
5. В коммите волны — контракт `docs/contracts/offers.md` и строка этапа 3в в `docs/board.md` платформы; здесь —
   статус волны (§5) и журнал `PROJECT_BRAIN.md` §8.
6. Параллельно работают чаты поиска и чаты шефа: перед работой `git fetch`, при сведении сохранять обе стороны.

7. **Стили на выкладку собирать с Flux Pro** (с 20.10 платформа использует платный Flux Pro; ключа на Mac нет):
   перед `npm run build` для выкладки — `rsync … zrok@159.195.5.15:/home/zrok/app/platform/vendor/livewire/flux-pro/
   platform/vendor/livewire/flux-pro/` (папка `vendor` не в git), иначе собранный CSS теряет классы Flux Pro
   (20.10: 466 КБ вместо 538 КБ — у «Карточки авто» пропало бы оформление). `composer install` локально падает на 401 —
   работать на уже стоящем `vendor`; тесты с компонентами Flux Pro (`flux::accordion`) локально падают — это не наша ошибка.
8. **Ссылка оффера для клиента (`/o/`) — свой переключатель `ZROK_PUBLIC_LINKS`** (решение владельца 20.10, вместе с «Анализом» `/a/`):
   открыта без входа и при закрытых на время тестов карточках (`ZROK_PUBLIC_CARDS=false`); закрыть — `ZROK_PUBLIC_LINKS=false`.
   Клиент видит отправленный вариант (`clientView`), архивный — 404 (`docs/contracts.md` платформы).
